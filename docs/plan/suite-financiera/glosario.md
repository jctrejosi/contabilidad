# Glosario

Lenguaje común para el plan y la implementación. Si un término cambia de
significado, se actualiza aquí y en el módulo correspondiente.

| Término | Definición |
|---|---|
| **ADS / Advantage** | Advantage Data Server, motor legado del sistema contable original |
| **Asiento** | Documento contable con cabecera y líneas; debe cuadrar débitos y créditos |
| **Auxiliar** | Cuenta de detalle o informe de movimientos por cuenta/tercero |
| **Base gravable** | Valor sobre el que se calcula un impuesto |
| **Cartera (CxC)** | Cuentas por cobrar; derechos pendientes de cobro |
| **Cierre** | Proceso que consolida el periodo, bloquea escrituras y genera apertura |
| **Compañía** | Entidad contable independiente con PUC, periodos y secuencias propias |
| **Comprobante** | Documento o diario que agrupa movimientos (recibo, egreso, compra) |
| **Conciliación** | Enlace entre movimientos del libro y extractos/pagos para explicar diferencias |
| **Consolidación** | Agregación de varias compañías en un libro consolidado con eliminaciones |
| **Contabilizar** | Convertir un documento validado en asiento inmutable |
| **CxP** | Cuentas por pagar; obligaciones pendientes de pago |
| **CUFE / CUDE** | Código único de factura electrónica / de nota electrónica ante la DIAN |
| **DIAN** | Dirección de Impuestos y Aduanas Nacionales (Colombia) |
| **Diario** | Agrupador contable (ventas, compras, banco, caja) con secuencia propia |
| **Débito / Crédito** | Naturaleza de cada línea; el asiento debe cuadrar |
| **ESFA** | Estado de Situación Financiera de Apertura (NIIF) |
| **Exógena** | Información de operaciones con terceros que se reporta a la DIAN |
| **ICA** | Impuesto de Industria y Comercio (municipal) |
| **Idempotencia** | Propiedad por la cual repetir un comando no duplica su efecto |
| **Impuesto** | Tributo calculado sobre una base (IVA, retención, ICA) |
| **IVA** | Impuesto sobre el Valor Agregado |
| **Ledger / Libro** | Registro de asientos contabilizados; fuente de verdad |
| **Lote** | Conjunto de líneas en borrador que se valida y luego se contabiliza |
| **Medios magnéticos** | Presentación electrónica de información exógena ante la DIAN |
| **Moneda funcional** | Moneda en la que se lleva la contabilidad de la compañía |
| **NIIF** | Normas Internacionales de Información Financiera |
| **NIT** | Número de Identificación Tributaria (9 dígitos + DV) |
| **Partida abierta** | CxC/CxP pendiente de pago o aplicación |
| **PUC** | Plan Único de Cuentas (Colombia) |
| **Posición fiscal** | Regla que ajusta impuestos/cuentas según tercero o jurisdicción |
| **Posteo** | Acto de contabilizar un documento y generar sus efectos |
| **Presupuesto** | Plan de ingresos/gastos por cuenta, centro y periodo |
| **Reversión** | Asiento espejo que anula el efecto de otro, conservando trazabilidad |
| **Retención** | Descuento tributario practicado en un pago o causación |
| **ReteIVA** | Retención sobre el IVA |
| **ReteICA** | Retención sobre el ICA |
| **Snapshot** | Copia inmutable de un informe con hash y firma |
| **Tercero** | Cliente, proveedor, empleado u otra entidad con NIT/documento |
| **UVT** | Unidad de Valor Tributario; se usa para bases y topes |
| **Secuencia** | Numeración autorizada de documentos, sin huecos ni reutilización |
| **Validar** | Verificar reglas de un documento antes de contabilizarlo |
